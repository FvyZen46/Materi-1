Apa itu Bahasa Pemrograman?

Bahasa pemrograman adalah bahasa khusus yang dipakai manusia untuk memberi instruksi kepada komputer. Instruksi itu disebut kode. Komputer hanya mengerti angka 0 dan 1, jadi kode yang kita tulis diterjemahkan oleh compiler atau interpreter.

Jenis bahasa pemrograman

  • Tingkat rendah: dekat dengan mesin, cepat, sulit dibaca (Assembly).
  • Tingkat tinggi: mudah dibaca manusia (Python, JavaScript, Java).
  • Compiled: diterjemahkan sekaligus sebelum dijalankan (C, C++).
  • Interpreted: diterjemahkan baris demi baris saat dijalankan (Python, JavaScript).

Cara Membuat HTML, CSS & JavaScript

Tiga bahasa ini membentuk semua halaman web. HTML adalah kerangka, CSS adalah tampilan, JavaScript adalah perilaku. Kamu cukup memakai Notepad dan browser.

1. HTML: struktur

<!DOCTYPE html>
<html>
  <body>
    <h1 id="judul">Halo Dunia</h1>
    <button onclick="sapa()">Klik</button>
  </body>
</html>

2. CSS: tampilan

h1 {
  color: teal;
  font-size: 40px;
}

3. JavaScript: perilaku

function sapa() {
  document.getElementById("judul").textContent = "Halo, Programmer!";
}

Langkah: simpan file dengan akhiran .html, lalu buka di browser. Ubah kode, simpan, dan muat ulang halaman untuk melihat hasilnya.

Materi Penting untuk Pemula

Variabel & tipe data

Wadah penyimpan nilai: angka, teks, true/false.

nama = "Fvy"
umur = 17

Percabangan

Program mengambil keputusan dengan if / else.

if nilai >= 75:
    print("Lulus")

Perulangan

Mengulang perintah tanpa menulis ulang.

for i in range(3):
    print(i)

Fungsi

Blok kode yang bisa dipakai berulang kali.

def sapa(n):
    return "Hai " + n

Array / list

Menyimpan banyak data dalam satu variabel.

buah = ["apel", "jeruk"]

Debugging & Git

Mencari dan memperbaiki error, serta menyimpan riwayat perubahan kode dengan Git.

Bahasa Pemrograman Populer

Python

Sintaks paling mudah. Cocok untuk pemula, data, dan AI.

print("Halo Dunia")

C++

Sangat cepat. Dipakai untuk game engine dan sistem.

#include <iostream>
int main(){
  std::cout << "Halo";
}

Java

Dipakai untuk aplikasi Android dan sistem perusahaan.

System.out.println("Halo");

PHP

Bahasa sisi server untuk membuat website dinamis.

<?php echo "Halo"; ?>

SQL

Bahasa untuk mengelola dan mengambil data dari database.

SELECT * FROM siswa;

Kotlin & Dart

Dipakai untuk membuat aplikasi mobile Android dan Flutter.

Kesimpulan

Bahasa pemrograman adalah alat untuk memberi perintah kepada komputer. Tidak ada bahasa yang paling hebat. Pilihlah sesuai tujuanmu.

  • Web: HTML untuk struktur, CSS untuk tampilan, JavaScript untuk interaksi.
  • Dasar yang wajib dikuasai: variabel, percabangan, perulangan, fungsi, dan debugging.
  • Python cocok untuk awal belajar, C++ untuk performa, Java dan Kotlin untuk Android, SQL untuk data.
  • Kunci utamanya adalah logika berpikir dan latihan yang konsisten.
Mulai dari satu proyek kecil hari ini: sebuah kalkulator, daftar tugas, atau halaman profil. Error itu normal, dan setiap error mengajarkan sesuatu.
